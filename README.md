# Total E'Clips Salon

A modern website for a 40-year-old neighborhood hair salon in Smithfield, Utah.

## Live

[totaleclips.vientapps.com](https://totaleclips.vientapps.com)

## Design

"Totality" — the salon's name is an eclipse pun, so the page is built from the two
states of an eclipse: a dark hero with a gold-rimmed disc of light rising into it,
then a bright page below. The palette is pulled from the salon's own storefront sign
(deep maroon board, cream serif lettering). Type is Fraunces over Karla.

The structural idea is that this salon has no front desk: four stylists each keep
their own book, so the four direct phone numbers are the spine of the page rather
than a "Book now" button.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Google Maps embed
- IntersectionObserver
